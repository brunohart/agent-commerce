# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Argue about the work, not the person.
- Assume the other person is trying to get it right.
- A label dispute or a failure-mode report is a gift, including when it is blunt. Receive it as one.
- No harassment, no personal attacks, nothing you would not say in a room with the person.

It applies in issues, pull requests, discussions and anywhere else the project is represented.

## Reporting

If something here falls short of this, contact the maintainer privately through their GitHub profile, or use GitHub's "Report content" option on the comment. Reports are read by the maintainer, not by a scheduled run, and are kept private.
